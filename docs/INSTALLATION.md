# PZL Return-to-Sport – Installation (Windows und Mac)

Adresse: **https://rockenschaub11-afk.github.io/pzl-return-to-sport/**

Die App läuft im Browser und lässt sich wie ein Programm installieren. Danach startet sie aus dem Startmenü bzw. Dock, funktioniert **ohne Internet** und aktualisiert sich selbst, sobald eine neue Version veröffentlicht ist.

> **Wichtig – wo die Daten liegen:** Alle Kürzel und Testungen liegen nur im Browser *dieses* Laptops (und nur in *diesem* Browser). Kein Server, keine Cloud.
> Deshalb: **einmal pro Woche eine Gesamtsicherung** (Menü „Sicherung“) und die Datei an einem sicheren Ort ablegen (z. B. USB-Stick). Die App erinnert daran.
> Browserdaten nicht löschen („Verlauf/Websitedaten löschen“ für diese Seite) – sonst sind die Daten weg, wenn keine Sicherung existiert.

## Windows – Microsoft Edge oder Google Chrome

1. Adresse oben öffnen.
2. In der Adresszeile rechts auf das Symbol **„App installieren“** klicken (Bildschirm mit Pfeil), alternativ:
   - **Edge:** Menü **…** → **Apps** → **Diese Website als App installieren**
   - **Chrome:** Menü **⋮** → **Streamen, speichern und teilen** → **Seite als App installieren** (je nach Version: **PZL Return-to-Sport installieren**)
3. **Installieren** bestätigen. Die App öffnet sich in einem eigenen Fenster.
4. Optional: Rechtsklick auf das Symbol in der Taskleiste → **An Taskleiste anheften**.

## Mac – Safari (ab macOS Sonoma)

1. Adresse oben in **Safari** öffnen.
2. Menü **Ablage** → **Zum Dock hinzufügen …** → **Hinzufügen**.
3. Die App liegt im Dock und im Ordner „Programme“.

## Mac – Google Chrome

1. Adresse oben in **Chrome** öffnen.
2. Rechts in der Adresszeile auf **„Installieren“** klicken oder Menü **⋮** → **Streamen, speichern und teilen** → **Seite als App installieren**.
3. Die App liegt danach im Launchpad und im Ordner „Chrome-Apps“.

## Gut zu wissen

- **Offline:** Nach dem ersten Öffnen funktioniert die App ohne Internet.
- **Updates:** Kommen automatisch. Ist eine neue Version da, lädt die App einmal neu – Eingaben sind dann schon gespeichert.
- **Mehrere Browser/Laptops:** Jeder Browser hat seine eigenen Daten. Zum Übertragen: Gesamtsicherung exportieren und auf dem anderen Gerät unter „Sicherung → Datei importieren“ einlesen (wird zusammengeführt).
- **Kürzel an Kolleg:innen:** Auf der Seite des Kürzels „Übergeben“ – Datei und Passwort getrennt weitergeben.
- **Deinstallieren:** Edge/Chrome: in der App oben rechts **…** → **Deinstallieren**; Mac/Safari: App aus dem Ordner „Programme“ löschen. *Vorher sichern* – beim Deinstallieren kann der Browser die Daten mitlöschen.
- Die App ist eine **Dokumentations- und Rechenhilfe** – sie ersetzt keine ärztliche Freigabe.
